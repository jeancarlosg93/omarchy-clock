# Screenshot provenance

The original five images are native Wayland screenshots of Omarchy Clock 2.1.2, captured with `grim` on 2026-10-12. `focus-intervals.png` is a native 2560×1440 fullscreen capture from version 2.1.3, using the app’s `--capture --demo --focus interval --fullscreen` mode on the same date. The app was isolated on an otherwise empty workspace. Windowed captures include only the app’s bounds and border; the fullscreen capture includes only the app, excluding the desktop bar, other applications, notifications, cursor, and wallpaper.

The current Omarchy theme was Catppuccin Latte. Timer, stopwatch, and activity values come from the temporary in-memory demo fixture (`--test-bar`), not the user database. The world clocks show live time. `stopwatch.png` shows Focus mode; `compact-small.png` shows the 160×110 minimum. The other main windows were 1200×1050. Borders add six pixels to each capture's dimensions.

The screenshots are included under the repository's MIT license. PNG provenance metadata records the capture origin. No personal screenshots, runtime data, or desktop review captures are included.
